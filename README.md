# WHAT'S INSIDE?

A fast daily game about guessing what's inside real food products.

## Current prototype

- 15-second rounds
- English / Spanish interface
- Ingredient entry separated by commas
- Instant feedback and scoring
- Results reveal found and missed ingredients

## Deploy

This repository is published with GitHub Pages using GitHub Actions. Every push to `main` triggers a deployment.

The current game is a static HTML prototype. Product data and ingredient answers are sample content for the first playable build; the next step is connecting a curated Open Food Facts catalog and improving bilingual ingredient matching.

## Run locally

Open `index.html` in a browser.
